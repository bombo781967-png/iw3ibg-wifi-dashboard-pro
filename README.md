# OVS WiFi Dashboard PRO
Independent Android application. Java 17 / Gradle 8.9. GitHub Actions build.yml generates debug APK. Enable precise location and Wi-Fi; disable mobile data for ICMP tests. DNS/TCP/HTTPS use selected Wi-Fi Network. Graphs show last 60 samples, not seconds. RF scanner uses Android cached results. No noise/SNR/retry metrics. Build and device testing pending.
